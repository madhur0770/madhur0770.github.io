Research: glaucoma detection with deep learning

M.Tech research at MNNIT Allahabad, supervised by Prof. Dharmendra Kumar Yadav, and ongoing. The system takes one fundus (retina) photograph, finds the optic disc, outlines the disc, cup and parapapillary atrophy, measures the cup-to-disc ratio, and returns a calibrated glaucoma probability with a heat map and an image-quality warning.

Results from the project's own evaluation, compared with a re-implemented classical image-processing pipeline
MeasureClassicalThis system
Disc Dice / cup Dice (522 test photos)0.771 / 0.4480.978 / 0.904
Vertical cup-to-disc ratio error0.1780.031
Glaucoma AUC on clinical diagnoses (411 eyes)0.6020.877

On RIGA-BinRushed, where six ophthalmologists graded every eye, out-of-fold accuracy against their consensus is 92.7%; the best single doctor scored 91.1%. All six networks run inside the browser, so a photo is never uploaded. This is a research prototype, not a medical device.

GraphCite

Python, Neo4j, Streamlit, LLM APIs

Multi-hop question answering over a knowledge graph. Every extracted relation keeps the sentence it came from, and each sentence of an answer is checked for a citation and for word-level support in the cited evidence. Unsupported statements are flagged instead of trusted. A demo mode runs without any model or database.
